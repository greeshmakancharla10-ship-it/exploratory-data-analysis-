# Student Performance Analysis Using Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Student Performance in Exams dataset to identify patterns, trends, and factors that influence students' academic performance. The analysis focuses on Mathematics, Reading, and Writing scores and examines the impact of demographic and educational factors.

## Objectives

* Analyze student performance data.
* Identify key factors affecting exam scores.
* Explore relationships between different variables.
* Generate visualizations to uncover patterns and trends.
* Present insights in a structured and understandable format.

## Dataset Information

The dataset contains information about students, including:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch Type
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## Project Workflow

### 1. Data Collection

* Uploaded the Student Performance dataset into Google Colab.

### 2. Data Understanding

* Examined dataset structure, dimensions, and feature information.
* Generated descriptive statistics.

### 3. Data Cleaning

* Checked for missing values.
* Removed duplicate records.
* Verified data consistency.

### 4. Feature Engineering

* Created an Average Score feature using Math, Reading, and Writing scores.

### 5. Exploratory Data Analysis

* Analyzed score distributions.
* Compared performance across genders.
* Studied the impact of lunch type and test preparation courses.
* Investigated relationships between exam scores.

### 6. Data Visualization

* Histograms
* Bar Charts
* Box Plots
* Correlation Heatmaps

### 7. Insight Generation

* Identified significant factors influencing academic performance.
* Highlighted relationships among subject scores.

## Key Findings

* Students who completed the test preparation course generally achieved higher scores.
* Reading and Writing scores showed a strong positive correlation.
* Students with standard lunch tended to perform better academically.
* Parental education level influenced student performance.
* Female students often performed better in Reading and Writing subjects.

## Results

The analysis successfully uncovered meaningful patterns and trends in student performance data, helping to understand factors that contribute to academic success.
